# Instrucciones para el portafolio

- Antes de modificar contenidos, artículos, interfaces o estilos, lee [EDITORIAL-DESIGN-SYSTEM.md](EDITORIAL-DESIGN-SYSTEM.md). Aplica sus reglas de identidad, retícula, tipografía, énfasis, navegación y accesibilidad.
- Reutiliza los tokens y componentes compartidos. Si cambia una regla editorial, actualiza la implementación y el documento en la misma revisión.
- Conserva el relato aprobado, datos, fechas, anclas e interacciones. Solicita aprobación para cambios sustantivos del contenido.
- Verifica en navegador las páginas afectadas y sus idiomas disponibles. Registra el alcance real de las comprobaciones.
- Mientras se revisa una versión editorial, entrega bajo `test-QA/`. Mantén las rutas y estilos de producción intactos hasta que el propietario apruebe explícitamente su publicación.
