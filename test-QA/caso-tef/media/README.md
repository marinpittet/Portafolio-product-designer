# Medios del caso TEF

Los recursos de esta carpeta se sirven desde GitHub Pages. Las pantallas, comprobantes y la cortina de éxito son mockups representativos entregados para este caso, con datos de ejemplo. La cortina conserva el WebM con marco de iPhone y ofrece una versión MP4 sin transparencia para Safari en iPhone, junto con una imagen inicial.

El benchmark ilustrativo identifica instituciones por nombre y logotipo; sus recorridos y estados son sintéticos.
