# Medios del caso TEF

Los recursos de esta carpeta se sirven desde GitHub Pages. Las pantallas, comprobantes y la cortina de éxito son mockups representativos entregados para este caso, con datos de ejemplo. La animación se sirve en WebM y usa el GIF entregado como póster.

El benchmark ilustrativo identifica instituciones por nombre y número; sus recorridos y estados son sintéticos. No se publican logotipos bancarios.
